# Changelog

All notable changes to this project are tracked here, keyed to the version in `package.json`.

## [0.5.0] - Shipped

Scripting, NPC agents and scene-owned rendering (PR #5).

## [0.4.0] - Not yet implemented

MCP and tool calls for AI integration. Planned but skipped so far — shipped out of order after 0.5.0.

## [0.1.0] - Shipped

Foundational engine and editor work: UI-free scene graph/component/render-bridge core, editor Phase 1 MVP (primitives, gizmo, hierarchy, inspector, undo/redo), shared `RenderHost`, performance measurement harness, editable quad meshes with a non-destructive modifier stack, additional mesh primitives (Torus, Tube, Icosphere) and modifiers, and Cloudflare Workers deploy integration.

## Planned

- **0.6.0** - More 2D and 3D tools
- **0.7.0** - Save and load system
- **0.8.0** - Arduino and external hardware support
- **0.9.0** - Optimizing
- **0.9.5** - Game engine
